# Notes Application

A simple and responsive **Notes Application** built using React and Tailwind CSS. It provides a clean interface for creating and managing notes.

## 🚀 Live Demo

[View Notes Application](https://notes-application-twzl.vercel.app/)

## 🛠️ Technologies Used

- React
- Tailwind CSS
- JavaScript
- Vite

## ✨ Features

- Create and manage notes
- Clean and responsive UI
- Reusable React components
- Tailwind CSS styling
- Deployed using Vercel
